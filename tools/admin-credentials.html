Admin Credentials Generator

Create the three values your deployment needs for admin login — everything happens in this browser tab. Nothing is sent anywhere.

ADMIN_EMAIL
ADMIN_PASSWORD_HASH
SESSION_SECRET
What to do with these values: open your hosting provider's "Environment Variables" settings (e.g. Vercel → your project → Settings → Environment Variables) and add all three using the exact names shown above, then redeploy. Sign in at /admin/login using the email and password you typed above (not the generated hash — that's only for the server to verify your password).

To generate a new password later, just reopen this file, enter a new password, and update ADMIN_PASSWORD_HASH in your hosting provider's settings.
